# Skill: Admin Dashboard

## Funcionalidades
- Resumen métrico (pendientes, aprobadas, rechazadas).
- Tabla de reservas pendientes con acciones de Aprobar y Rechazar.
- Inclusión de modal de notas administrativas.
- CRUD visual para inventario de equipamiento.

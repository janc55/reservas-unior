# Skill: React Vite Frontend

## Principios
1. Estructura modular de componentes, servicios, hooks y páginas.
2. Diseño responsive con UI limpia y elegante, adaptada a los colores institucionales de UNIOR (Azul/Dorado/Gris).
3. Separación de lógica de datos (servicios/hooks) de los componentes visuales.
4. Estados de carga (spinners/skeletons), vacíos (empty states) y manejo claro de errores en pantalla.

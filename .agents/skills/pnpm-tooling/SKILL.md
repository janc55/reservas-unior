# Skill: pnpm Tooling

## Principios
1. Usar únicamente `pnpm` para instalar, remover o ejecutar dependencias y scripts.
2. Mantener un único archivo de bloqueo `pnpm-lock.yaml`.
3. Ejecutar scripts con `pnpm run <script>`.
4. Especificar engines de Node.js y pnpm en `package.json`.
